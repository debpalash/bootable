ISO · USB

Write an ISO to USB and verify it.

Bootable inspects the image, limits target selection to removable drives, and reads raw writes back before reporting success.

Image inspection decides the method

Open a local ISO or choose an image from the catalog. Bootable inspects it before a target can be reviewed. A hybrid Linux or Unix ISO normally uses a raw byte-for-byte write. A Windows installer ISO uses the FAT32 construction path instead.

If the download has a publisher checksum sidecar or manifest, Bootable selects the strongest supported digest and refuses a mismatch. When no checksum is available, the interface states that clearly.

Select the physical drive

Insert the USB drive and identify it by model, capacity, device path, and any available serial suffix. Fixed disks, read-only devices, and drives containing the running system root are not eligible.

Target selection is destructive. Capacity alone is not enough to identify a drive. Check the physical device before confirming erasure.

Write the ISO

  1. Choose the ISO and wait for inspection to finish.
  2. Select the removable USB drive.
  3. Open Review and check the write strategy, ordered operations, and target identity.
  4. Acknowledge permanent erasure.
  5. Start the write and keep the drive connected through verification.

Immediately before opening the target, the helper discovers it again by stable ID and compares its capacity and safety flags with the reviewed plan.

Read-back verification

For a raw write, Bootable hashes the image bytes while streaming, flushes the target, then reads back exactly the written image length and compares SHA-256. Extra space after the image on a larger drive is not part of the comparison.

A matching result confirms that the intended byte range reached the target. It does not prove that the image supports every firmware or computer.

Cancellation

Cancellation stops at a controlled boundary, flushes completed raw output, and marks the media incomplete. Rewrite the full image before trying to boot it.
