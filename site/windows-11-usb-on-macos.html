Windows installer · macOS

Create a Windows 11 USB on macOS.

Bootable uses native macOS disk tools, a fixed root-owned helper, and wimlib to build verified FAT32 installer media.

Current macOS support

The alpha supports Apple Silicon. It discovers whole removable devices, excludes the macOS root disk, unmounts the selected target, and writes through its raw device path.

For Windows installer media, the source ISO is mounted read-only. Bootable creates GPT or MBR FAT32 media with diskutil and copies the validated setup tree.

Before you start

  • An Apple Silicon Mac.
  • A trusted Windows 11 ISO.
  • An expendable USB drive with enough capacity.
  • wimlib when the ISO contains an oversized WIM or CA 2023 files are requested.
brew install wimlib
curl -fsSL https://bootable.palash.dev/install.sh | sh -s -- --gui

The alpha is not signed or notarized. macOS may show a security warning. Review the installer and release SHA-256 file before running it.

Install the protected helper

The installer places the fixed helper at /Library/PrivilegedHelperTools/app.bootable.helper after administrator authentication. The desktop app remains unprivileged. Bootable rejects a helper that is not protected by root ownership.

Create the installer

  1. Open the Windows 11 ISO in Bootable.
  2. Select the USB drive by its physical model and capacity.
  3. Choose GPT or MBR and any required Windows setup options.
  4. Review the source, target, operations, dependencies, and permanent erasure.
  5. Confirm the reviewed plan and authenticate when macOS asks.
  6. Keep the drive connected through the final boot-tree check.

What happens after copying

Bootable checks the UEFI boot tree, Windows setup payload, split WIM sequence, and FAT32 size rules. Cancellation terminates controlled media tools and marks the drive incomplete so it is not mistaken for finished media.

The structural check does not guarantee that Windows Setup will complete on every target computer.
