Raspberry Pi · IMG · SD

Write a Raspberry Pi image to an SD card.

Browse Pi images or open a local IMG, write the expanded bytes, and verify the target before removing it.

Choose a Raspberry Pi image

Open the Raspberry Pi catalog in Bootable, search the available images, and queue a download. You can pause, resume, cancel, or retry the job. A local .img, .raw, or supported compressed file works through the same inspection path.

When a publisher checksum file is available, Bootable verifies the downloaded file before allowing it into a write plan. The interface distinguishes a verified checksum from an HTTPS-only download.

Check the real capacity

Compressed files can be much smaller than the disk image they contain. Bootable measures the full expanded length before review and checks that the expanded image fits the card.

Bootable also provides destructive bad-block and fake-capacity tests. Run those only on expendable media; the test itself overwrites the selected device.

Write the card

  1. Choose a catalog image or local file.
  2. Insert the SD card through a removable or USB-attached reader.
  3. Select the whole card, not a mounted partition.
  4. Review the expanded size, physical target, and permanent erasure.
  5. Write and wait for read-back verification.

Check the adapter and card. The selected target is the entire removable device. Existing partitions and files will be erased.

What gets compared

For compressed media, Bootable hashes the expanded stream sent to the card. It then reads the same byte range back from the card and compares SHA-256. Verification covers the written bytes, not whether a specific Pi model supports the image.

After the write

Wait for the safe-removal result before disconnecting the reader. If the write was cancelled or the verification failed, rewrite the entire image. Do not treat an interrupted card as bootable.
