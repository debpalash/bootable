01 · Discovery

Catalogs and downloads

DistroWatch catalog
Search releases; browse six-month popularity, Arch, and Debian views.
Curated sources
Omarchy and Raspberry Pi catalogs use the same source flow.
Local images
Open ISO, IMG, RAW, or supported archives with native dialogs.
Managed downloads
Check space; queue, pause, resume, cancel, and retry. Transfers run one at a time, FIFO.
Persistent state
Validate HTTP Range; retain owned partials and history; delete only owned files.
Publisher checksums
Use the strongest supported digest. A mismatch blocks writing.
Honest fallback
No publisher digest means HTTPS-only, not publisher-verified.
Catalog cache
Loading, ready, empty, failed, retry, cached, and stale states. Fresh for 30 minutes; stale data survives refresh failure.

02 · Plan

Source and target safety

Seven source formats
ISO, IMG, RAW, XZ, gzip, Zstandard, and bzip2.
Expanded size
Measure expanded bytes before review and capacity checks.
Whole-disk targets
Accept USB-attached or explicitly removable whole disks. Partitions are not eligible targets.
Device refresh
Rescan while idle; lock the target list during writes.
System-disk exclusion
Reject fixed, read-only, system-root, and undersized targets.
Reviewed write plan
Show source, device, strategy, dependencies, operations, and permanent effects.
Plan-bound confirmation
GUI and TUI require acknowledgment. CLI uses a target-specific phrase.
Stable-ID recheck
Rediscover the device; compare capacity and safety flags before opening it.
Narrow elevation
The app stays unelevated. A protected helper receives the plan and rechecks the target.

03 · Write

Raw writing and drive tools

Raw image writing
Stream ISO, IMG, and RAW bytes directly to removable media.
Streaming decompression
Write XZ, gzip, Zstandard, and bzip2 without an unpacked copy.
Raw read-back
Hash while writing, flush, read back the written range, and compare SHA-256.
Controlled cancellation
Stop cleanly, flush completed output, and mark the target incomplete.
Write telemetry
Phase, percentage, bytes, speed, ETA, elapsed time, verification, and safe removal.
Bad-block checks
One, two, or four destructive patterns on Linux.
Fake-capacity checks
Exercise the whole removable device on Linux. Destructive.
Drive backup
Atomic RAW, IMG, or DD backups on Linux and macOS. Existing files are never overwritten.

04 · Windows installers

FAT32 Windows media

GPT or MBR
Create one FAT32 Microsoft Basic Data partition for UEFI setup media.
UDF sources
Read Microsoft UDF-only trees through 7-Zip when ISO-9660 is incomplete.
WIM splitting
Split install.wim into a complete install.swm sequence for FAT32.
Pre-erasure checks
Reject missing boot files, collisions, irregular files, and oversized payloads.
Post-copy audit
Check UEFI files, payloads, split-WIM parts, and FAT32 size rules.
Ten setup choices
Hardware bypass, offline or local account, region, privacy, BitLocker, QoL policies, CA 2023, SkuSiPolicy, and S Mode.
WIM tools
Windows DISM, Linux wimtools, or macOS wimlib.
Firmware scope
UEFI only. Legacy BIOS helpers are not implemented.

05 · Interfaces

GUI, TUI, and CLI

Native desktop
GPUI with mouse controls, native dialogs, responsive layout, and background work.
Mouse-enabled TUI
Ratatui with keyboard, mouse, terminal breakpoints, and the full feature set.
CLI
Inspect images, list safe targets, confirm a specific plan, and run supported operations.
GUI/TUI parity
Same labels, order, plans, progress, cancellation, states, errors, retries, and Windows choices.
Linux
Removable discovery, root exclusion, PolicyKit helper, backup, Windows media, and drive tests.
Windows
USB PhysicalDrive inventory, one-use UAC token, volume detachment, raw writing, and Windows media.
macOS
Whole-removable inventory, root exclusion, private helper socket, raw writing, backup, and Windows media.
Developer checks
Read-only QEMU/OVMF boot tests and a root-only loop-device write harness.

Current limits

Not implemented

  • Platform code signing and macOS notarization
  • Legacy BIOS helpers for constructed Windows media
  • Linux persistence and persistent multiboot
  • Windows To Go
  • DOS and FreeDOS media
  • VHD, VHDX, and FFU backup
  • OpenPGP or minisign publisher verification
  • Localization
  • General-purpose FAT, NTFS, UDF, exFAT, or ext formatting
  • Official ISO and UEFI Shell downloads
  • Silent unattended installation
