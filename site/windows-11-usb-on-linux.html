Windows installer · Linux

Create a Windows 11 USB on Linux.

Bootable builds a FAT32 Windows installer from an ISO, splits oversized WIM files, and checks the finished boot tree.

What Bootable creates

Bootable inspects the Windows ISO and creates one FAT32 Microsoft Basic Data partition on the selected removable drive. You can choose GPT or MBR. Current Windows media targets UEFI boot; legacy BIOS helpers are not implemented.

If install.wim is too large for FAT32, Bootable uses wimlib-imagex to create install.swm and numbered parts. It then checks the UEFI files, Windows payload, split set, and FAT32 file-size limits.

Before you start

  • A Windows 11 ISO from a source you trust.
  • An expendable USB drive large enough for the ISO contents.
  • wimtools for oversized WIM payloads and CA 2023 boot files.
  • Administrator authentication for the protected write helper.

On Debian or Ubuntu:

sudo apt install wimtools
curl -fsSL https://bootable.palash.dev/install.sh | sh -s -- --gui

The USB drive will be erased. Bootable excludes fixed and system disks, but you must still confirm the physical device before writing.

Create the installer

  1. Open Bootable and choose the Windows 11 ISO.
  2. Insert the USB drive and select it by model and capacity.
  3. Choose GPT or MBR and review any Windows setup options.
  4. Open Review. Check the source, target, partitioning, file operations, and erasure warning.
  5. Acknowledge the consequences and start the write.
  6. Wait for the boot-tree verification and safe-removal result.

Windows setup options are explicit. Bootable shows them in the reviewed plan and does not silently apply hardware, account, privacy, BitLocker, regional, or policy changes.

What verification covers

Before erasure, Bootable checks the installer tree, regular files, answer-file collisions, and FAT32 limits. After copying, it checks UEFI boot files, the Windows setup payload, and every split WIM part.

This confirms the required media structure. It does not prove that setup will complete on every PC.
