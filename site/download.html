Install

Linux or macOS

The installer downloads the matching archive, verifies its SHA-256 sidecar, and asks for administrator authentication only when it installs the write helper.

# Desktop
curl -fsSL https://bootable.palash.dev/install.sh | sh -s -- --gui

# Terminal
curl -fsSL https://bootable.palash.dev/install.sh | sh -s -- --tui

# Both
curl -fsSL https://bootable.palash.dev/install.sh | sh -s -- --all

Review install.sh before piping it to a shell. Set BOOTABLE_SKIP_PRIVILEGED_HELPER=1 for a non-writing install.

Windows

Download the ZIP and SHA-256 file above, verify the archive, extract it, then run:

powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Variant All

The installer copies Bootable under Program Files. The interface remains unelevated; UAC appears when an approved write starts.

Verify the archive yourself

The sidecar proves the downloaded archive matches the release file. GitHub build provenance ties that archive to the release workflow. It is not a substitute for platform code signing.

Linux, macOS, and GitHub provenance

# Linux
sha256sum -c bootable-*.sha256

# macOS
shasum -a 256 -c bootable-*.sha256

# GitHub provenance; use the archive you downloaded
gh attestation verify bootable-0.1.0-alpha.2-x86_64-unknown-linux-gnu.tar.gz \
  --repo debpalash/bootable

Windows PowerShell

$asset = "bootable-0.1.0-alpha.2-x86_64-pc-windows-msvc.zip"
$expected = (Get-Content "$asset.sha256" -Raw).Split(" ")[0]
$actual = (Get-FileHash $asset -Algorithm SHA256).Hash.ToLower()
if ($actual -ne $expected) { throw "SHA-256 mismatch" }

Platform support

  • Linux x86-64Raw/compressed images, Windows installers, and RAW backup. Split WIM and CA 2023 operations require wimtools.
  • Windows 10+ x86-64Raw/compressed images and Windows installers. RAW backup is unavailable.
  • macOS Apple SiliconRaw/compressed images, Windows installers, and RAW backup. Split WIM and CA 2023 operations require wimlib.

Known limits

  • Only the newest published alpha receives fixes.
  • Constructed Windows installer media targets UEFI; legacy BIOS helpers are not implemented.
  • Linux persistence, Windows To Go, DOS media, and multiboot are not implemented.
  • Release packages are limited to the three platform and architecture pairs listed above.
  • Verification checks source bytes, written bytes, or the Windows boot tree. It does not prove an operating-system installation will finish.

Something failed?

Include the Bootable version, host platform, interface, image name and version, target model and capacity, failed stage, and visible error. Remove serial numbers and private paths.
