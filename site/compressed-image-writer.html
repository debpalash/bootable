XZ · gzip · Zstandard · bzip2

Write compressed disk images directly.

Bootable measures the expanded image, streams it to removable media, and verifies the expanded target bytes.

Supported formats

Bootable recognizes XZ, gzip, Zstandard, and bzip2 around raw disk images and hybrid ISOs. You can open a local file or use a catalog download. Manual extraction is not required.

Expanded-size preflight

The compressed file size is not used for drive capacity checks. Bootable fully measures the decompressed stream during inspection, then builds the write plan with the expanded byte count.

This extra inspection pass catches truncated or invalid compressed sources before the target is erased and prevents a small archive from being planned against a card that cannot hold its contents.

Streaming write

  1. Open the compressed image and wait for inspection.
  2. Select a removable drive larger than the measured expanded size.
  3. Review both the source file and expanded byte count.
  4. Confirm erasure and start the write.
  5. Leave the media connected through read-back verification.

Decompression feeds the writer directly. Bootable does not need to keep a second, fully extracted image beside the archive.

Two different integrity checks

A publisher checksum, when available, validates the compressed file you downloaded. Post-write verification validates the expanded byte stream written to the target. These checks cover different stages and are reported separately.

Cancellation and failure

A decompression error stops the operation. Cancellation is checked during inspection and writing. Any interrupted target is marked incomplete and needs a full rewrite.

Keep enough local free space for the download. Manual extraction is unnecessary, but the compressed source still needs a complete local file.
