Ratatui · mouse · keyboard

Write boot media from a terminal.

Bootable's TUI supports catalog browsing, downloads, target review, writing, cancellation, and verification without a desktop window.

Install the TUI

curl -fsSL https://bootable.palash.dev/install.sh | sh -s -- --tui
bootable

Linux x86-64 and macOS Apple Silicon use the Unix installer. Windows users can install the TUI from the release ZIP with install.ps1 -Variant Tui.

One terminal workflow

  1. Discover a catalog image or choose a local file.
  2. Wait for inspection and checksum status.
  3. Select an eligible removable drive.
  4. Review the source, target, strategy, operations, and consequences.
  5. Confirm erasure, follow progress, and wait for verification.

Mouse clicks, wheel scrolling, and keyboard navigation reach the same controls. The terminal layout reflows for available geometry but keeps the Source → Target → Review order.

Desktop and TUI parity

The TUI and GPUI desktop app consume the same core sessions and plans. Loading, cached, empty, failure, retry, cancellation, and stale-response states have matching behavior. Write progress includes phase, percentage, transferred bytes, throughput, ETA, elapsed time, verification, and safe-removal result.

Writing without running the TUI as root

The interactive TUI stays unprivileged. After the destructive consequences are acknowledged, it launches the fixed protected helper and asks the operating system for administrator authentication. Catalog and download code never enters the helper process.

CLI commands

The bootable binary also exposes non-interactive commands. Run bootable --help for the commands supported by the installed version. Destructive CLI writes require the exact plan-bound confirmation phrase; never hard-code a device path in automation.

Do not launch the whole TUI with sudo. Install the protected helper and let Bootable request elevation only for the reviewed write.
